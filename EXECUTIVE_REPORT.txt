3. UPDATED CORE FEATURES
------------------------------------------------------------------------
* Message-Level Signal State Isolation (New Fix):
  Instead of relying on a global switch value that modifies the styling of the entire conversation history, the system now captures and stores the exact state of "signalEnabled" inside each message object at the moment it is dispatched.
  - Signal ON messages maintain their colored highlights (<signal> parsing) permanently.
  - Signal OFF messages render in plain, clean text, even when the global switch is later toggled.

* Dynamic Greetings Pool:
  An array pool of 10 welcoming prompts (e.g., "Evening", "How can I help you today?", "Let's build something") dynamically updates on page refresh or when starting a "New Chat".

* Functional Hamburger Drawer & Sidebar:
  Clicking the menu opens a smooth slide-in sidebar menu that triggers "Start New Chat" to clear current conversation parameters and reset the random greeting state.

* Viewport Responsiveness:
  - Mobile (h-[100dvh] + overflow-hidden) is locked to prevent default browser bounces/scaling issues.
  - Desktop (sm:max-w-[390px] + sm:h-[844px] + overflow-y-auto on body) shows a standard centered phone mock frame and enables page scrolling if the window height is small.
